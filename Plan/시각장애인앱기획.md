# **스마트폰 기반 실내/건물 안내 서비스 기획서 (확장판)**

---

## **1. 프로젝트 개요**

### 1-1. 목표

* 시각장애인을 위한 **실내 및 건물 안내 서비스** 개발. 관공서및 행사 안내앱을 목표
* 우선 코디세이 건물화면으로 PC로 테스트, 가능하면 안드로이드 앱개발, 실시간 구동 
* 스마트폰 카메라를 이용하여 책상, 탁자, PC 모니터, 계단, 복도 등 **실내 환경 인식**.
* YOLO 및 Detectron2 기반 **인스턴스/파노프틱 세그멘테이션 기술** 활용 레이블 제작
* yolon-seg로 학습시킨 모델 이용 추론
* **객체 + 공간 구조**를 동시에 인식하여 시각장애인에게 음성 안내 제공.
* 디버깅을 위하 실시간 클래스 인식장면을 촬영이미지위에 오버레이 표시 

### 1-2. 필요성

* 시각장애인은 실내 구조를 직관적으로 이해하기 어려움.
* 기존 시각장애인 안내 앱은 객체 단위 인식만 가능하여 복잡한 실내 구조 탐지에는 한계.
* 실내 구조물, 복도, 벽, 바닥 등을 인식하면 **정확한 경로 안내** 가능.
* 인터페이스는 음성 안내


### 1-3. 활용 사례

* 실내 경로 안내: 복도, 계단, 출입문 인식 → 안전 경로 안내.
* 환경 객체 탐지: 책상, 의자, PC 모니터 등 → 주변 정보 제공.
* 스마트폰 기반 실시간 추론 가능 → 외부 센서 불필요.

## **2. 기술 조사**

### 2-1. YOLO11 계열

| 모델          | 특징                 | 장점                          | 단점                           |
| ----------- | ------------------ | --------------------------- | ---------------------------- |
| YOLO11x     | COCO 등 다양한 데이터셋 학습 | 객체 검출 성능 우수, 다양한 사전학습 모델 존재 | 공간 구조 인식 어려움, semantic 정보 부족 |
| YOLO11n-seg | 인스턴스 세그멘테이션 가능     | 모바일 환경에서 추론 가능              | semantic segmentation 변환 어려움 |

* **적용 방안**:

  * YOLO11x: 사전 학습된 객체 검출 모델 → 초기 라벨 생성용.
  * YOLO11n-seg: 스마트폰에서 실시간 추론 → 시각장애인 안내용.

---

### 2-2. Detectron2 계열

| 모델                    | 특징                        | 장점                                          | 단점                           |
| --------------------- | ------------------------- | ------------------------------------------- | ---------------------------- |
| Mask2Former           | Detectron2 기반 인스턴스 세그멘테이션 | 객체 + 공간(Stuff) 인식 가능, ADE20K Panoptic 모델 활용 | 클래스 수 제한 확인 필요               |
| Panoptic Segmentation | 인스턴스 + semantic 통합        | 객체와 공간 동시 인식 가능                             | COCO보다 ADE20K가 실내 구조물 인식에 유리 |

* **주요 특징**:

  * Mask2Former: 실내 구조물(벽, 바닥, 복도 등) 인식 가능.
  * Panoptic Segmentation: Stuff + Thing 통합 라벨링 가능 → 공간까지 추론 가능.

---

### 2-3. 라벨링 전략

* **수동 라벨링**: YOLO11x 활용 가능 → 작은 데이터셋 학습용.
* **자동 라벨링**: Mask2Former → ADE20K Panoptic pretrained 모델 활용 → 객체 + 공간 라벨 생성.
* **병행 전략**:

  1. YOLO11x-seg로 객체 라벨 수동 생성 → 학습 데이터 구축.
  2. Mask2Former로 공간 라벨 생성 → YOLO11n-seg 학습 시 데이터 보강.

---

## **3. 실험 설계**

### 3-1. 데이터 수집

* 스마트폰으로 촬영한 실내 환경 사진 활용.
* 대상: 책상, 탁자, PC 모니터, 계단, 복도, 벽, 바닥 등.
* 데이터 수집 기준:

  * 다양한 조명 환경 반영.
  * 다양한 각도와 거리에서 촬영.
  * 충분한 객체/공간 수 확보.

### 3-2. 데이터 라벨링

* **객체 라벨**: 책상, 의자, PC 모니터, 사람 등.
* **공간 라벨**: 복도, 벽, 바닥, 계단 등.
* YOLO11x와 Mask2Former 병행 활용:

  * YOLO11x: 초기 객체 라벨링.
  * Mask2Former: 공간 및 객체 라벨 자동화.
* 라벨링 결과 → YOLO11n-seg 학습 데이터셋 구축.

### 3-3. 모델 학습 및 추론 플로우

1. **라벨 생성**: Mask2Former(ADE20K Panoptic)로 공간 + 객체 라벨 생성.
2. **YOLO11 학습**: YOLO11n-seg/YOLO11x-seg 학습.
3. **스마트폰 추론 테스트**: YOLO11n-seg 모델을 스마트폰에 적용 → 실시간 성능 확인.
4. **성능 평가**:

   * 인식 클래스 정확도.
   * 공간 구조 인식률.
   * 스마트폰 연산 속도 및 배터리 효율.

### 3-4. 실험 목표

* 객체 + 공간 인식 정확도 향상.
* 실내 구조물 및 복도, 계단, 벽 등 필수 공간 단위 인식.
* 실시간 스마트폰 추론 가능 여부 확인.

## **4. 기술 비교 및 모델 선정 고려사항**

| 기준      | YOLO11x      | YOLO11n-seg      | Mask2Former(ADE20K)            |
| ------- | ------------ | ---------------- | ------------------------------ |
| 학습 데이터  | COCO 등 객체 중심 | COCO + 세그멘테이션    | ADE20K Panoptic, Stuff + Thing |
| 공간 인식   | 제한적          | 일부 가능            | 우수                             |
| 모바일 적용  | 제한적          | 가능               | 모델 크기 커서 모바일 추론 제한 가능          |
| 라벨링 난이도 | 수동 라벨 필요     | 수동/자동 혼합 가능      | 자동 라벨링 가능                      |
| 활용 목적   | 객체 탐지        | 객체 + 인스턴스 세그멘테이션 | 객체 + 공간 + 파노프틱 세그멘테이션          |

* **결론**:

  * YOLO11n-seg: 모바일 실시간 추론 가능 → 시각장애인 안내 앱 최적.
  * Mask2Former: 실내 공간 인식 및 라벨 자동 생성 → 학습 데이터 구축 필수.
